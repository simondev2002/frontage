Frontage · app preview

A browser stand-in for the iOS app, screen for screen, running the real flow against your local server. Sign in with email (the code is shown because no email provider is configured), build a site, edit it, publish it, read messages.

Simulated on the web

  • Sign in with Apple and StoreKit purchases only exist on a device. The paywall's "Subscribe" fakes the plan via a localhost-only dev route.
  • AI generation and edits need ANTHROPIC_API_KEY in server/.env; without it jobs fail with a clear message. The seeded "Oak & Ember" site lets you test everything else.
  • Push notifications don't apply; new messages still appear in the inbox.
